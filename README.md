# EDA Project

Minimal structure for exploratory data analysis (EDA).

## Folders

- `data/raw/` – original, immutable data dumps
- `data/interim/` – intermediate transformed data
- `data/processed/` – analysis-ready datasets
- `notebooks/` – EDA notebooks
- `src/` – reusable code (loading, cleaning, features, plotting helpers)
- `reports/` – exported results (figures, tables, notes)
- `models/` – trained models / artifacts (ignored by git by default)
- `references/` – data dictionaries, links, papers, notes
